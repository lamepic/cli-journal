# cli-journal

A lightweight command-line journal app. Write, view, edit, and delete journal entries directly from your terminal. Entries are stored as Markdown files and rendered with terminal formatting when viewed.

## Features

- Create journal entries with a title and content
- List all entries
- View entries with Markdown rendering in the terminal
- Append to or overwrite existing entries
- Delete entries

## Requirements

- Node.js 20+
- pnpm

## Getting Started

### Install dependencies

```bash
pnpm install
```

### Run in development

```bash
pnpm dev <command> [options]
```

### Build

```bash
pnpm build
```

### Run the built CLI

```bash
pnpm start <command> [options]
```

### Install globally (optional)

After building, link the CLI globally so you can run `journal` from anywhere:

```bash
npm link
```

## Usage

### Add a journal entry

```bash
journal add -t "My Title" -c "Today I learned..."
```

### List all entries

```bash
journal list
```

### View an entry

```bash
journal view --id <id>
```

### Edit an entry (append by default)

```bash
journal edit --id <id> -c "Additional content"
```

### Overwrite an entry

```bash
journal edit --id <id> -c "Replacement content" --overwrite
```

### Delete an entry

```bash
journal delete --id <id>
```

## Project Structure

```
src/
  index.ts    # CLI commands (add, list, view, edit, delete)
  journal.ts  # Journal CRUD logic
  db.ts       # JSON database read/write
  types.ts    # TypeScript interfaces
  db.json     # Entry index (auto-created)
  content/    # Markdown files for each entry (auto-created)
dist/         # Compiled output (generated by `pnpm build`)
```

## Tech Stack

- [Commander](https://github.com/tj/commander.js) — CLI argument parsing
- [Chalk](https://github.com/chalk/chalk) — Terminal color output
- [marked](https://github.com/markedjs/marked) + [marked-terminal](https://github.com/mikaelbr/marked-terminal) — Markdown rendering in the terminal
- [tsup](https://tsup.egoist.dev/) — TypeScript bundler
- [tsx](https://github.com/privatenumber/tsx) — TypeScript execution for development
